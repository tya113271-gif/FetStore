=======================================================
   متجر FET STORE V2 — دليل الاستضافة والتشغيل المجاني
=======================================================

أهلاً بك يا بطل! تم تعديل وتجهيز المتجر ليعمل على منصات الاستضافة السحابية المجانية (مثل Render.com) بكل سلاسة وسرعة وبدون أي تعقيد.

-------------------------------------------------------
⚡ التعديلات والتحسينات التي تمت على المتجر:
-------------------------------------------------------
1. ضبط عنوان الخادم على (0.0.0.0):
   - يتيح للموقع قبول اتصالات الزوار من جميع أنحاء العالم على الاستضافات السحابية.
2. إضافة ملف `package.json`:
   - لتتعرف منصة الاستضافة تلقائياً على أن المشروع Node.js وتقوم بتشغيله فوراً.
3. دعم كامل لجميع روابط الشراء والدفع:
   - أصبح بإمكانك وضع أي رابط شراء لمنتجاتك (سواءً Tebex، أو رابط تذكرة ديسكورد، أو سلة، إلخ) دون أي قيود، مع فتح الرابط بتبويب جديد للزائر.
4. تبسيط كلمة مرور المدير:
   - تم تعديل الحد الأدنى لكلمة المرور ليصبح 6 خانات فأكثر (بدلاً من 12 خانة المعقدة).
5. نظام النسخ والاحتياط (Backup) في لوحة التحكم:
   - تمت إضافة تبويب "النسخ والاحتياط 💾" في FET MANAGER؛ لتحميل نسخة كاملة من متجرك بملف JSON على جهازك، واسترجاعها في أي لحظة بنقرة زر واحدة لحماية بياناتك على الاستضافات المجانية.
6. إضافة منتجات أولية جاهزة:
   - المتجر مزود بمنتجات ونماذج سكربتات QBCore أولية فخمة ليعمل المتجر بشكل ممتلئ وجذاب فور تشغيله.

-------------------------------------------------------
🚀 خطوات الاستضافة المجانية 100% على Render.com:
-------------------------------------------------------

الخطوة 1: رفع المشروع على حسابك في GitHub
- أنشئ مستودعاً جديداً (New Repository) في حسابك على GitHub، وسمّه مثلاً: `fet-store`.
- ارفع ملفات هذا المجلد داخل المستودع.

الخطوة 2: إنشاء الحساب على Render
- افتح موقع: https://render.com
- سجّل الدخول مجاناً بحساب GitHub الخاص بك (Sign in with GitHub).

الخطوة 3: تشغيل خدمة الويب (Web Service)
- في لوحة تحكم Render، اضغط على زر "New +" أعلى الصفحة ثم اختر "Web Service".
- اختر مستودع `fet-store` الذي رفعته على GitHub واضغط "Connect".
- في صفحة الإعدادات:
  * Name: اكتب اسم المتجر (مثلاً: `fet-store`).
  * Environment: اختر `Node`.
  * Region: اختر الأقرب (مثلاً Frankfurt أو أي منطقة).
  * Build Command: اتركه فارغاً أو اكتب `npm install`.
  * Start Command: اكتب `node server.js` (أو `npm start`).
  * Instance Type: اختر الخيار المجاني: "Free".
- اضغط بالأسفل على زر: "Deploy Web Service".

الخطوة 4: مبروك! موقعك شغال على الإنترنت 🌐
- سيعطيك Render رابطاً مجانياً مشفراً بـ SSL (https) مثل:
  `https://fet-store.onrender.com`
- افتح الرابط واستمتع بمتجرك المباشر!

-------------------------------------------------------
🔒 الدخول للوحة تحكم المدير (FET MANAGER):
-------------------------------------------------------
1. افتح موقعك وانزل لأسفل الصفحة (Footer) واضغط على "FET MANAGER ↗".
2. أول مرة فقط: أنشئ اسم مستخدم إنجليزي وكلمة مرور (6 أحرف أو أكثر).
3. بعد تسجيل الدخول، ستتمكن من:
   - تعديل المنتجات والأسعار وإضافة سكربتات جديدة.
   - وضع روابط الشراء الخاصة بك.
   - تعديل نصوص المتجر وشعار الموقع وروابط الديسكورد.
   - تنزيل نسخة احتياطية من متجرك بضغطة زر واحدة.
